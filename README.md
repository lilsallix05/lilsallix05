## Selected work

| Project | What I built and why it matters |
| --- | --- |
| **[Ransomware Detection Lab](https://github.com/lilsallix05/ransomware-detection-lab)** | **15 Sigma rules** for Windows/AD ransomware precursors, replayed against attack-like and benign events. Generates SPL/KQL and an analyst report that links alerts to source evidence. Benign hits are reported, not quietly erased. |
| **[Selat Watch](https://github.com/lilsallix05/selat-watch)** | An explainable phishing-domain investigation desk: Unicode lookalikes, brand-impersonation signals, analyst decisions, and **SHA-256-hashed evidence exports**. A priority score is deliberately **not** a phishing verdict. |
| **[Pocket SOC](https://github.com/lilsallix05/pocket-soc)** | A local incident desk for small Malaysian organisations. Normalises Wazuh, Suricata, and Zeek-style logs; preserves original records and a hash-linked case history; prepares **human-reviewed** PDPA notification drafts. |
| **[SunSOC](https://github.com/lilsallix05/sunsoc)** | An investigation training range with **8 synthetic cases, 157 log events, and 24 scored findings**. Learners must cite evidence for their answers—not just guess the right outcome. |
| **[Pause · Money-Mule Job Checker](https://github.com/lilsallix05/mule-job-checker)** | A student-focused job-offer checker using **20 explainable red-flag rules** and exact-text highlights. Reports what deserves verification instead of claiming an offer is fraudulent or safe. |
| **[SunCTF 2026 Challenges](https://github.com/lilsallix05/sunctf-2026-challenge)** | Two original challenges I authored: **The Eternal Flame** (OSINT geolocation) and **The Gaslit Gallery** (a Flask/Docker web challenge designed to reward reading the code rather than trusting an AI-generated answer). |

**How to read these projects:** The repositories document their test fixtures, limitations, and next validation steps. Much of the security telemetry is **synthetic**; I don't present lab results or mocked integrations as evidence of production deployment.
